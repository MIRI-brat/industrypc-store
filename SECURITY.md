# Аудит безопасности INDUSTRYPC

## XSS

Для отображения данных используется React JSX. Пользовательский ввод не вставляется в HTML через innerHTML или dangerouslySetInnerHTML.

## SQL Injection

Проект не использует серверную базу данных и SQL-запросы. Данные каталога загружаются из локального JSON-файла.

## Валидация формы

Поля формы являются обязательными. Для имени и телефона установлены ограничения максимальной длины.

## Защита данных

Персональные данные пользователей не сохраняются в базе данных. Форма используется как демонстрационная.

## HTTPS

При публикации проекта рекомендуется использовать HTTPS/SSL-сертификат. Для локальной разработки HTTPS не требуется.

## Вывод

В рамках текущей клиентской версии проекта основные риски XSS и SQL Injection учтены архитектурой приложения.
